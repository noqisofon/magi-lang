# magi-lang

失敗コンテキスト + Rust 構文な組み込み言語に近いんじゃないかなと思います。

## 特徴

### 失敗が暗黙に伝播する

`Result` を返す処理の失敗は、Rust の `?` 演算子を書かなくても呼び出し元へ自動的に伝播します。
エラー処理のためのボイラープレートを減らし、正常系の流れだけを素直に書けることを狙っています。

### Rust 風の構文

構文は Rust に近いものにしています。Rust に慣れている人が読み書きしやすい見た目を目指しています。

### 組み込み言語を目指す

Rust 製アプリケーションに埋め込んで使えるスクリプト言語を目指しています。
