# magi-lang

Verse 言語の失敗コンテキストと Rust 構文を合わせた、組み込み言語です。

## 特徴

### 失敗が暗黙に伝播する

失敗はエフェクトとして扱われ、失敗しうる式は、囲んでいる失敗コンテキストへ暗黙に伝播します。`?` のような明示的な記述は要りません。

### Rust 風の構文

構文は Rust に近いものにしています。Rust に慣れている人が読み書きしやすい見た目を目指しています。

### 組み込み言語を目指す

Rust 製アプリケーションに埋め込んで使えるスクリプト言語を目指しています。
